❓ Perguntas Frequentes

Posso pular áreas?

Dentro do mesmo nível, algumas áreas são independentes. Mas a ordem geral importa — cada nível constrói sobre o anterior. Se já sabe algo, marque como estudado e siga.

Quanto tempo por dia?

1-2h por dia, 5 dias/semana. Consistência > intensidade. Use o botão "📚 Estudo do Dia" pra saber por onde continuar.

Preciso de hardware?

Pra 95% do roadmap, qualquer computador com 4GB+ RAM. Pra Eletrônica, use simuladores (Tinkercad). Um Arduino Uno (~R$50) é opcional.

Os livros são obrigatórios?

Não. Use os botões ▶ YouTube e 🔍 Google de cada item. Livros são pra aprofundamento.

Meu progresso é salvo?

Sim, no navegador (localStorage). Use 📥 Exportar pra fazer backup. 📤 Importar pra restaurar em outro navegador.

Posso reprovar no quiz?

Sim! Refaça quantas vezes quiser. Precisa de 80%. Só o último resultado é salvo.
