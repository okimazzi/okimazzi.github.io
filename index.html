❓ Perguntas Frequentes

Posso pular áreas?

Dentro do mesmo nível, algumas áreas são independentes (ex: Matemática e Web no Iniciante). Mas a ordem geral é importante — cada nível constrói sobre o anterior. Se já sabe algo, marque como estudado e siga em frente.

Quanto tempo por dia preciso estudar?

O roadmap foi pensado pra 1-2h por dia, 5 dias por semana. Nesse ritmo, o Iniciante leva ~6-12 meses. Mais importante que horas é consistência — 1h todo dia é melhor que 8h no sábado.

Preciso de hardware especial?

Não! Pra 95% do roadmap, qualquer computador com 4GB+ de RAM roda. Pra Eletrônica/Embarcados, você pode usar simuladores (Tinkercad, Wokwi) sem hardware. Se quiser, um Arduino Uno (~R$50) é suficiente.

Os livros são obrigatórios?

Não. Os livros são referência de aprofundamento. Pra começar, use os termos de busca de cada item no YouTube/Google — há conteúdo gratuito excelente. Livros são pra quando você quer dominar o assunto de verdade.

Meu progresso é salvo?

Sim, no seu navegador (localStorage). Não precisa de conta. ⚠️ Se limpar dados do navegador, o progresso é perdido. O botão "Resetar progresso" apaga tudo propositalmente.

Posso reprovar no quiz e tentar de novo?

Sim! Você pode refazer qualquer quiz quantas vezes quiser. Só o último resultado é salvo. Precisa de 80% pra aprovação.

💡 Como usar este roadmap:
1. Comece pelo 🟢 Iniciante, na ordem — cada área depende da anterior.
2. Clique nos itens pra expandir e veja "O que estudar" com detalhes.
3. Use os botões ▶ YouTube e 🔍 Google pra abrir buscas diretamente.
4. Marque itens como ✅ estudado clicando no checkbox — seu progresso é salvo automaticamente.
5. Faça a 📝 prova de cada área — precisa de 80% pra aprovação. Resultado é salvo.
6. Complete os projetos 🟢 básico e 🔴 avançado de cada área pra fixar o aprendizado.
7. Só avance de nível quando se sentir confortável com ~80% dos itens.
